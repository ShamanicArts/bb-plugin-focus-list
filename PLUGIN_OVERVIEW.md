BB's sidebar thread list with focus decay, so current work stays in front without archiving anything.

## What you get

- Idle projects fade gradually; hover restores them, and the open project never fades.
- Threads idle for a few days fold into **Show N older threads**; open, pinned, unread, running and waiting threads stay visible.
- A draggable, collapsible **Parked** divider: projects below it tuck behind one row and form a ready-made archive-audit list.
- Everything from BB's own list: pinned threads, custom sections, organize by project/machine/time, nesting, worktree grouping, drag to reorder, keyboard shortcuts.

## How it works

A fork of BB's bundled thread-list plugin. Activity is the latest of agent updates, reads and attention requests. Settings live under Organize → Focus or `bb focus-list prefs`. Your existing layout is imported from BB's list on first run.
